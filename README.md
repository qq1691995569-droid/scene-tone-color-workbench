# 场景调色 Scene Tone

公开版：https://qq1691995569-droid.github.io/scene-tone-color-workbench/

## 启动

直接打开公开链接即可使用。需要在本机运行时，安装 Node.js 后执行 `npm install` 和 `npm start`，再打开 http://127.0.0.1:8765 。所有图片和调色计算都留在当前浏览器中，不会上传到服务器。

同一局域网内的同事可以通过启动日志中显示的局域网地址访问，例如 `http://10.10.3.85:8765/`。运行服务的电脑需要保持开机并持续运行 `npm start`；网络切换后局域网 IP 可能变化，请以新的启动日志为准。

## 使用流程

1. 导入目标图和参考图（PNG / JPEG / WebP）。支持选择文件、拖入图片；点击对应图片区域后按 Ctrl+V 粘贴。替换图片会清空当前去偏色和通透度优化。
2. 可先点“一键初调”统一整体色调。新版会分别匹配黑位、暗部、中间调、亮部、白位，并按阴影、中间调和高光分别处理色温，避免暖色铺满整张图。两张图片不要求位置、构图一致。AI 生成的 JPG / PNG 默认按 sRGB 处理。
3. 点击“查看效果”：拖动分界线比较原图与结果，或切换“参考图 / 调整结果”并排查看。点击“匹配参考光感”会分析参考图相对目标图的黄蓝、绿洋红偏移；“产品本色保护”会降低高饱和产品色受到的影响。
4. 画面显得灰、闷或有滤镜感时，点击“智能通透优化”，再用强度滑杆控制效果。全局冷暖、色偏、饱和度、明暗和对比度也可以直接在预览中调整。
5. 产品颜色不同但需要继承相同光感时，点击“匹配产品材质光感”。工具会自动寻找主要彩色材质，保留目标色相，只迁移参考材质的明暗层次、饱和关系和环境偏色。识别到错误主体时点“主体不对？点选提示”，依次在目标图和参考图的产品上各点一次。
6. 确认效果后，点击顶部按钮导出原尺寸 PNG。

## 算法与限制

“匹配参考光感”比较目标图与参考图中的低彩度候选像素，分别计算阴影、中间调和高光的 LAB 色偏，再按亮度平滑应用。高彩度像素会按“产品本色保护”降低校正权重，使蓝色沙发等产品保留原有色相，同时获得参考图的环境偏色感受。检测并不是白平衡测量，复杂彩色灯光下仍需检查结果。

“智能通透优化”匹配参考图的亮度层次并加入受控的局部对比度，同时保护高光，减少整层滤镜覆盖的感觉。它不会重绘家具、改变结构或复制参考图的光影。

材质识别使用颜色聚类和柔和色相权重，不进行语义分割，也不会生成或重绘物体。同色家具或大面积木材可能成为自动候选，此时用一次点击提示目标、再点击提示参考即可重新锁定材质颜色。

高饱和颜色超出 sRGB 时会向中性轴平滑压缩，避免通道硬裁切造成的断色。“自然度”会限制一次调整的感知色差。拖动滑杆时使用较轻的即时预览，停止拖动后自动恢复高质量预览；原尺寸导出始终运行完整算法。

主页面的绿色/红色选区只控制全局初调的统计取样，不会限制最终调色范围。工具不再做物体识别或局部选区调整。

建议 sRGB 输入；导出为浏览器 sRGB PNG，保留透明度，不保留原图 EXIF 或原始 ICC。预览长边最多 1200 像素；输入限制 5000 万像素，导出保留输入尺寸。
