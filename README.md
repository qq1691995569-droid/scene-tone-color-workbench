# 场景调色 Scene Tone

## 启动

直接打开公开链接即可使用。需要在本机运行时，安装 Node.js 后执行 `npm install` 和 `npm start`，再打开 http://127.0.0.1:8765 。所有图片和调色计算都留在当前浏览器中，不会上传到服务器。

同一局域网内的同事可以通过启动日志中显示的局域网地址访问，例如 `http://10.10.3.85:8765/`。运行服务的电脑需要保持开机并持续运行 `npm start`；网络切换后局域网 IP 可能变化，请以新的启动日志为准。

## 使用流程

1. 导入目标图和参考图（PNG / JPEG / WebP）。支持选择文件、拖入图片；点击对应图片区域后按 Ctrl+V 粘贴。替换图片会清空当前去偏色和通透度优化。
2. 可先点“一键初调”统一整体色调，再微调全局参数。两张图片不要求位置、构图一致。
3. 点击“查看效果”：拖动分界线比较原图与结果，或切换“参考图 / 调整结果”并排查看。明显偏红、偏绿、偏黄或偏蓝时，点击“智能去偏色”；工具会判断偏色方向，并显示可继续微调的去偏色强度。
4. 画面显得灰、闷或有滤镜感时，点击“智能通透优化”，再用强度滑杆控制效果。全局冷暖、色偏、饱和度、明暗和对比度也可以直接在预览中调整。
5. 确认效果后，点击顶部按钮导出原尺寸 PNG。

## 算法与限制

“智能去偏色”比较目标图与参考图中的低彩度候选像素，分别计算阴影、中间调和高光的 LAB 色偏，再按亮度平滑应用。高彩度像素会降低校正权重，以减少对肤色、木材和绿植的影响。检测并不是白平衡测量，复杂彩色灯光下仍需用强度滑杆检查结果。

“智能通透优化”匹配参考图的亮度层次并加入受控的局部对比度，同时保护高光，减少整层滤镜覆盖的感觉。它不会重绘家具、改变结构或复制参考图的光影。

主页面的绿色/红色选区只控制全局初调的统计取样，不会限制最终调色范围。工具不再做物体识别或局部选区调整。

建议 sRGB 输入；导出为浏览器 sRGB PNG，保留透明度，不保留原图 EXIF 或原始 ICC。预览长边最多 1200 像素；输入限制 5000 万像素，导出保留输入尺寸。

## 验证

`npm test` 检查 LAB 处理、智能去偏色、通透度优化、透明度、导入路由及原尺寸分块一致性。
